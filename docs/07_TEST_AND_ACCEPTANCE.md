# Правила учёта и поведения бота

## 7.1. Обязательные инварианты

- **INV-01:** В каждой финансовой операции сумма `ledger_entries.delta` равна нулю.
- **INV-02:** Баланс каждого обычного счёта >=0; системный эмитент — единственное специально обоснованное исключение.
- **INV-03:** Одна уникальная операция не может быть выполнена дважды по одному idempotency-key.
- **INV-04:** Одна регистрация на `(guild_id, discord_user_id)`; один стартовый перевод на гражданина.
- **INV-05:** Один уникальный объект имущества имеет ровно одного текущего владельца.
- **INV-06:** Ни один платёж бюджета не превышает доступную статью и остаток казны.
- **INV-07:** Нельзя повторно выплатить одно рабочее задание/контракт/зарплатный период.
- **INV-08:** Смена ставки налога не пересчитывает завершённые и уже принятые сделки.
- **INV-09:** Политическая игровая роль не предоставляет системных Discord-прав владельца.
- **INV-10:** Нет рабочих платежей/изменения власти без полномочий, все исключения аудируются.
- **INV-11:** Сбой Discord при уведомлении не приводит к повторному денежному переводу.
- **INV-12:** Не происходит случайной эмиссии через задания/зарплаты/сделки.

| AT-25 | Повторное вступление ранее зарегистрированного | Старый аккаунт восстановлен по правилам, +250 повторно не начисляется |
| AT-26 | Критический админский акт | В журнале есть актор, время, причина, объект и результат |

| AT-28 | Смена сезонных параметров и повторный запуск на той же БД для той же гильдии | Сохранились личные и корпоративные остатки, казна, проводки и право собственности. Начальный выпуск и стартовые гранты не продублировались |

| AT-30 | Проверка конфигурации операторов первого сезона и запуск с пустым списком допуска | До обращения к Discord проверяются назначения оператора госимущества, проверяющего NPC, арбитра и двух членов комиссии. Администратор вносит их в сохранённый список допуска. Игровые полномочия требуют допуска и регистрации. Экономика настраивается и при числе допущенных меньше 10 |
| AT-31 | Владелец предлагает гражданину объект за 200 ₵. Покупатель подтверждает перепродажу при ставке 2% | Списано 200 ₵, продавцу поступило 196 ₵, казне 4 ₵. Право перешло покупателю. Записи первичной покупки и перепродажи доступны для сверки |
| AT-32 | Покупатель дважды подтверждает одну перепродажу. Отдельно проверяются недостаток средств, отмена и подтверждение посторонним | Успешная продажа проведена ровно один раз. Отказы сохраняют деньги и право собственности |
| AT-33 | Новый владелец повторно перепродаёт тот же объект. Ставка меняется между предложением и подтверждением | Каждая успешная перепродажа оставляет своё подтверждение и проводки. Ранее предложенная цена и налог сохраняются |
| AT-34 | Публичное голосование за импичмент достигает избирательного кворума и двух третей голосов за. Два независимых члена комиссии подтверждают итоги | После первой подписи полномочия прежние. После второй президент теряет полномочия, а мандаты депутатов сохраняются. Недостаток голосов, отсутствие кворума и повторная подпись того же человека не прекращают мандат |
| AT-35 | Президент отстранён при открытых выборах, при подтверждённом преемнике и при отсутствии обоих | Существующие выборы или преемник сохраняются. В последнем случае комиссия может открыть одни внеочередные выборы на новый срок 28 дней |
| AT-36 | Опубликовано больше десяти открытых NPC-заданий и поступило больше десяти результатов для проверки | Следующая страница показывает оставшиеся записи по сроку или времени сдачи. Очередь проверки доступна назначенным проверяющим |
| AT-37 | Создано больше десяти доступных пользователю госконтрактов | На следующих страницах доступны более старые заказы. Видимость зависит от участия в контракте или действующих казённых полномочий |
| AT-38 | Подтверждённого гражданина убрали из списка допуска между голосованиями | Его ID сохраняется в старом снимке. Новые выборы, повтор после ничьей, замена отменённого повтора и новый опрос об импичменте используют актуальный допуск при расчёте состава и кворума |
| AT-39 | Администратор добавляет и удаляет допуск через Discord, в том числе повторным запросом | Допуск меняется один раз с аудитом, действует сразу и сохраняется после перезапуска. У обычного игрока доступ закрыт. Повторный допуск восстанавливает доступ к прежнему гражданину и его счёту без нового гранта |
| AT-40 | Discord-администратор выбирает игровую роль и канал отчёта, меняет или очищает настройки | PostgreSQL хранит настройки и аудит. Фоновые задачи используют сохранённые значения. Неподходящая или повторно используемая роль отклоняется. Отчёты в очереди сохраняют исходный канал |
| AT-41 | Президент выдвигает верховного судью, двое действующих депутатов подписывают назначение | После первой подписи мандат отсутствует. Вторая независимая подпись открывает один мандат на 28 дней. Повтор подписи, конфликт интересов и попытка обойти полномочия не создают мандат |
| AT-42 | Судья рассматривает дело и выносит решение по редакции закона | Редакция действовала на момент события. Конфликт интересов требует отвода. Оправдание не запускает исполнение |
| AT-43 | Граждане обжалуют решение отдельным публичным голосованием | Бот фиксирует снимок избирателей и подтверждённый итог. При отмене бот возвращает удержанный штраф, прекращает заключение и снимает приостановку акта по этому делу |
| AT-44 | Судья указывает статью и числовые пределы штрафа, исполнение запрашивается одновременно | Назначенная сумма проходит пределы статьи и сезона. Повтор не дублирует проводки. При недостатке средств сохраняется полная сумма к списанию после пополнения. После окончания срока апелляции или сохранения решения удержанная сумма переходит из эскроу в казну. Публичный отчёт показывает агрегат |
| AT-45 | Вступившее в силу заключение проходит через перезапуск и истечение срока | Игровая роль, канал и ограничения команд сохраняются на назначенный срок. Апелляция доступна. По истечении срока ограничения снимаются |
| AT-46 | Два сенатора по очереди регистрируют опубликованную редакцию закона | До второй подписи редакция доступна только действующим сенаторам. Повтор не дублирует подпись. Новая редакция действует с указанной даты, старый текст доступен по номеру |
| AT-47 | Президент предлагает назначить или освободить прокурора, два сенатора подписывают | После первой подписи полномочия прежние. Вторая независимая подпись меняет состояние один раз. Полномочия сохраняются после окончания срока президента |
| AT-48 | Затронутый гражданин или прокурор оспаривает закон или указ | Жалоба связана с конкретной редакцией. Удовлетворённая жалоба немедленно приостанавливает её и возвращает акт принявшему органу. Поиск отдаёт последнюю предшествующую редакцию без приостановки, пока апелляция не восстановит оспоренную |
| AT-49 | Государственное обвинение предъявляют действующий прокурор и гражданин без этого мандата | Система принимает обвинение от уполномоченного прокурора. В случае конфликта судья получает отказ в вынесении решения |
| AT-50 | Стороны подают дела, судья назначает и переносит слушание | Повтор запроса не создаёт второе дело или слушание. Причастный судья не назначает заседание. Посторонний видит только сводку без личностей и материалов. После освобождения прокурора доступ представителя государства переходит к преемнику |
| AT-51 | Президент вносит опубликованный указ, независимый сенатор подтверждает, гражданин оспаривает редакцию | Черновик не принимается как предмет жалобы. После подтверждения дело связано с конкретной редакцией указа. Уголовное обвинение требует редакцию закона. Коды и даты указов и законов могут совпадать |
